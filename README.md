# CodeMap

**CodeMap** — это плагин для IntelliJ IDEA / Android Studio, который визуализирует цепочки вызовов функций в Kotlin-коде.

## Возможности
- 📊 Визуализация графа вызовов
- 🎨 Цветовая категоризация (UI, Network, Storage, Async, System)
- 🔍 Навигация по клику — переход в исходный код
- 🏛️ Проверка архитектурных паттернов (Clean Architecture, MVVM, SRP)
- ⚡ Совместимость с K2

## Установка
Установите из [JetBrains Marketplace](ссылка) или через IDE: Settings → Plugins → Marketplace → поиск "CodeMap"

## Использование
1. Откройте Kotlin-файл
2. Кликните правой кнопкой на функции → "Show CodeMap"
3. Исследуйте граф вызовов
