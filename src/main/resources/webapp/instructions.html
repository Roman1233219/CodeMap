🎨 Цветовая индикация (12+ категорий)

Цвет функции определяется автоматически на основе её типа и поведения в коде:

ACTION: Точки входа (onCreate, onStart) и команды.
REQUEST: Функции, возвращающие данные в точку вызова.
DATA_FLOW: Потоки данных (без прямого возврата результата).
ASYNC: Асинхронные вызовы (Coroutines, launch, delay).
UI: Работа с интерфейсом (setText, visibility, animate).
NETWORK: Сетевые запросы (API, fetch, execute).
STORAGE: Базы данных и настройки (Room, SharedPreferences).
STATE: Реактивные потоки (Flow, LiveData, emit, observe).
ANDROID: Системные вызовы (Intents, Services, Broadcasts).
INTERNAL: Внутренние методы вашего проекта.
LOG: Логирование (Log.d, println).
ERROR: Обработка ошибок (try-catch, runCatching).
UNKNOWN: Неопознанные вызовы.

💡 Системные вызовы: В корне проекта находится файл system_functions.json. Вы можете редактировать его, добавляя свои описания и цвета для функций любых библиотек.

🔎 Навигация и интерактив

Ветвление (Branching): Если функция содержит if-else или when, плагин предложит вам выбрать нужную ветку (True/False/Case) для продолжения цепочки.
Интенты и Переходы: Плагин отслеживает неявные связи. Если вы запускаете Activity через Intent, это отобразится в графе.
Фильтры: Используйте панель фильтров сверху, чтобы скрыть лишние типы (например, LOG или ANDROID) и не загромождать карту.
Умный поиск: Нажмите Ctrl+F, чтобы быстро найти любую функцию по названию.

🏗 Проверка архитектуры

Smart Detection: Плагин определяет слой (Data, Domain, Presentation) не по именам папок, а по реальным вызовам внутри файлов.
Контроль SRP: Если файл смешивает логику UI и Данных, вы получите предупреждение с перечнем конфликтующих функций.
Паттерны: Проверка MVVM/MVI/MVP на наличие запрещенных импортов (например, UI-библиотеки во ViewModel) и связей.

⚠️ Внимание: Удаление плагина

При деинсталляции плагина CodeMap из Android Studio его служебные файлы в проекте не удаляются автоматически. Для полной очистки проекта вам необходимо вручную удалить следующие объекты из корня вашего проекта:

  • Папку .codemap/ (содержит кэш анализа PSI.json)
  • Файл system_functions.json (ваши настройки системных вызовов)
